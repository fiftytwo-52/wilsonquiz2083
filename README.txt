Wilson Science Quiz 2083 - Offline Package
==========================================

1. Open index.html in any modern browser (Chrome/Edge/Firefox).
   Works with file:// directly or via http://localhost.

2. Optional music: place 'quiz-show-suspense.mp3' next to index.html
   to enable the background quiz-show music.

3. pdfs/ contains the Junior and Senior question-and-answer sheets
   (rules + all questions).
